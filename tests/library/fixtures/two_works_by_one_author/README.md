# Two works by one author

`carmina_prima` and `carmina_altera`, written as the item scripts write their output. Both are certain of `et`,
`Roma`, `est` and `.`, and macronize them alike. Carmina Prima is certain that `levis` is lĕvis (also the
sentence-initial `Levis`, whose state is 0), Carmina Altera that it is lēvis, except for one uncertain `levis` (mask 2)
that has its own macronization.

Carmina Prima has no books, as the Eclogues have none, so its references are made of a poem's n and a verse's, and they
all look like numbers. Carmina Altera has one book, with two poems: poem 10, whose title has the reference 1.10, and
poem 10a, which has no title.

Once the aggregate merges them, its output is also the reader's import fixture.
